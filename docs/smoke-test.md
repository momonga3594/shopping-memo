# スマホ実機スモークテスト（Phase 0）

本番 URL: https://momonga3594.github.io/shopping-memo/

このチェックリストは端末（スマートフォン）での通し確認用です。エージェントは端末を操作できないため、ユーザーが実施してください。

## 事前設定（⚙️）

1. チラシ画像プロキシ URL に次の値が最初から入っていることを確かめる（以前に空で保存した端末は入れ直す）:
   `https://shopping-memo-flyer-proxy.momonga3594.workers.dev`
2. 「プロキシ用シークレット」に、本番 Worker の `PROXY_SECRET` と **同じ値** を入れて保存する（2026-10-27 から必須。空や不一致だと店舗ボタン・URL読み込み・サムネイルがすべて 401 になり、チラシタブに設定を促す案内が出る）
3. AI整理／チラシ解析を試す場合は Gemini API キーを保存（キーは端末の localStorage のみ。リポジトリには置かない）

## チェック項目

- [ ] **メモ追加**: 商品名（＋任意の数量・購入先）を追加できる。「にんじん、玉ねぎ」のように「、」や改行で区切ると複数件になる
- [ ] **元に戻す**: × で消したとき・「完了を消す」のあと、下に出る「元に戻す」で戻せる（5秒）
- [ ] **完了の並び**: 完了にしたものが店のグループの下へ回る
- [ ] **購入先グループ**: 「イオン」「原信」など店舗ごとに見出し付きで並ぶ（未設定は末尾）
- [ ] **音声入力**: マイクで話し、入力欄に日本語テキストが入る（自動では追加しない）
- [ ] **AIで整理**: 雑な文からアイテムが抽出されリストへ追加される
- [ ] **チラシ（カメラ／ギャラリー）**: 写真から候補が出て、選択したものをメモへ追加できる
- [ ] **チラシ（画像URL）**: 公開画像の直リンクで読み込める（プロキシ経由）
- [ ] **チラシ（標準の店舗ボタン）**: 「ウオロク 神道寺」「イオン とやの店」「原信 黒崎」を押すと、URLを貼らずに画像一覧が出る
- [ ] **チラシ（ビューア resolve・任意）**: イオン／ウオロク／クラシル／原信の URL を貼ると画像一覧が出る  
  例（イオン店舗ページ）:  
  `https://www.aeon.com/store/イオン/イオンとやの店/`  
  例（イオンビューア・店舗・チラシIDは実際のものに差し替え）:  
  `https://chirashi.otoku.aeonsquare.net/viewer/index.html?d=sp&s_id=0000021780&f_id=f176358`  
  例（ウオロク店舗ページ）:  
  `https://www.uoroku.co.jp/shop/flyer/kandoji.html`  
  例（原信店舗ページ）:  
  `https://www.harashinnarus.jp/shops/kurosaki/`  
  例（クラシルウィジェット）:  
  `https://chirashi.kurashiru.com/widgets/3fca60ae-f69f-4001-9160-075b98b1a565/leaflets`

- [ ] **この特売で献立**: 候補にチェックして押すと3日分の献立が出て、「この日の買い足しをメモに追加」で買い足しがメモに入る（2回押しても重複しない）
- [ ] **ホーム画面に追加**: ホーム画面から全画面で開ける
